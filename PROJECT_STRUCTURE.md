# 📂 Project Structure — Smart Clock

This document provides a complete breakdown of the project's folder and file structure, including a description of each component's purpose.

---

## 🏗️ Root Directory
- **`platformio.ini`**: The core configuration file for PlatformIO. Defines the board (ESP32-C3), framework (Arduino), and all library dependencies.
- **`build.sh`**: A unified bash script for common tasks (build, flash, update web flasher assets).
- **`README.md`**: High-level user documentation, hardware list, and setup instructions.
- **`TECHNICAL.md`**: In-depth technical documentation covering architecture and library analysis.
- **`START_GUIDE.md`**: Step-by-step commands to build and run the project.
- **`PROJECT_STRUCTURE.md`**: (This file) A detailed map of all project components.

---

## 📁 `include/` — Header Files
Contains all C++ header files that define the classes and constants.
- **`config.h`**: Centralized configuration for hardware pins (SDA, SCL), WiFi AP settings, and OTA URLs.
- **`display.h`**: Defines the `DisplayManager` class, screen dimensions, and clock face enumerations.
- **`net.h`**: Defines the `NetManager` class for managing WiFi, NTP, and OTA functionality.

---

## 📁 `src/` — Source Code
Contains the implementation of the project logic.
- **`main.cpp`**: The principal application file. Handles setup, the main loop, button polling, and screensaver logic.
- **`display.cpp`**: Implementation of the `DisplayManager`. Contains the rendering code for the Digital, Analog, and Minimal clock faces.
- **`net.cpp`**: Implementation of the `NetManager`. Handles WiFiManager portal, NTP time synchronization, and HTTP OTA updates.

---

## 📁 `web/` — Web Flasher Assets
A directory containing the static files for the browser-based flasher.
- **`index.html`**: The main UI for the Web Flasher. Includes wiring instructions and the "Flash" button powered by ESP Web Tools.
- **`manifest.json`**: Tells the browser where to find each binary and at what memory offset to flash them.
- **`version.json`**: A metadata file for OTA updates, containing the version number and firmware URL.
- **`firmware.bin` / `bootloader.bin` / `partitions.bin`**: The compiled machine code generated by PlatformIO.
- **`boot_app0.bin`**: A support binary used by the ESP32 bootloader to manage boot partitions.

---

## 📁 `.pio/` — Build Output (Managed)
Automatically generated by PlatformIO.
- **`build/`**: Contains the compiled object files and final binaries for each environment. You should not modify files here.
- **`libdeps/`**: Contains the source code of external libraries downloaded from the registry.
